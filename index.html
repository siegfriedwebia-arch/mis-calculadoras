¿Cómo se calcula el IVA paso a paso?

Calcular el Impuesto sobre el Valor Añadido (IVA) es un proceso matemático básico pero fundamental para autónomos, empresas y consumidores. Dependiendo de si necesitas sumar el impuesto o desglosarlo, la fórmula cambia ligeramente.

Fórmula para añadir el IVA

Para sumarle el IVA a un precio base (llamado base imponible), debes multiplicar el importe por 1 más el porcentaje de IVA en formato decimal. Por ejemplo, para un IVA del 21%:

Precio Total = Base Imponible × 1.21

Fórmula para quitar o desglosar el IVA

Si tienes el precio total de un producto con el IVA ya incluido y quieres saber cuánto corresponde al producto y cuánto al impuesto, debes dividir el total entre 1 más el porcentaje de IVA en decimal:

Base Imponible = Precio Total ÷ 1.21
